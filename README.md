# Bordvol

Website voor Bordvol — gezonde, smaakvolle feestlunches en borrelplanken in Weesp.

🌐 Live op: https://bordvol.fit

## Structuur

- `index.html` — de volledige website (single-page)
- `assets/` — afbeeldingen, losse CSS/JS (indien nodig)
- `CNAME` — custom domain configuratie voor GitHub Pages

## Workflow

- Wijzigingen aan de site: direct op `index.html`, of via een branch bij grotere experimenten (bv. nieuwe copy-richting)
- Grote copy-experimenten altijd in een aparte branch — bevalt het niet, dan gooi je 'm weg zonder dat `main` rommelig wordt
